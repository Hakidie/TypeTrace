Generated by `npm run eval:ai` on 2026-11-23 with `gemini-3.5-flash-lite`. Do not edit by hand: run it again.

What it measures: for each of 20 cases the Weak spots lesson is built as in the app (`buildLesson`, a fixed random seed per case, so the same words each run), Gemini writes a passage from it (`lessonPrompt`, `weakSpotsAi.systemPrompts`), and the server checks it (`checkAiPassage`). A case **passes** when the passage has 20 to 200 words and uses at least 60 % of the practice words. A failed case is never shown to a learner: the lesson is a saved passage or the picked words. Each case is one call, so the rate is a small sample, not a guarantee.
